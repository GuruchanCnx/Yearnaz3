# Yearnaz

Short one-line description: Yearnaz is a static website built with plain HTML/CSS (and optional small JS). This repository contains the site source and assets.

Live demo
- Enable GitHub Pages for this repo and set the site to: https://GuruchanCnx.github.io/Yearnaz3
- Demo screenshot: add a screenshot at docs/screenshot.png and it will display here.

Quick start (local)
1. Clone:
   git clone https://github.com/GuruchanCnx/Yearnaz3.git
2. Serve locally (simple):
   python3 -m http.server 8000
   then open http://localhost:8000

What to check / improve
- Ensure index.html is at the repository root (or configure Pages to point to the folder that contains it).
- Add meta viewport in the head: <meta name="viewport" content="width=device-width, initial-scale=1">
- Add descriptive <title> and <meta name="description"> for basic SEO.
- Optimize images (compress or convert to WebP) and add alt text for accessibility.

Repository structure (suggested)
- index.html — main page
- css/ — styles
- images/ or assets/ — images and icons
- docs/ — screenshots or additional docs
